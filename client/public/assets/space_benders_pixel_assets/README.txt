Space Benders NASA cleanroom pixel-art assets

All files are RGBA PNGs with exact dimensions and nearest-neighbor resampling.
Use Phaser 3 texture filtering: scene.game.renderer.config.pixelArt = true, or set texture.setFilter(Phaser.Textures.FilterMode.NEAREST).

Files:
- floor_tile_32x32.png and wall_tile_32x32.png: 32px tiles
- *_station_64x64.png: four interactive station props
- artemis_assembly_bay_96x160.png: centerpiece
- mission_control_droid_32x32.png: NPC
- interaction_badge_E_32x32.png: interaction icon
